# وكلاء الذكاء الاصطناعي وإدارة المشاريع الرقمية

الموقع الرسمي للتقرير العربي المختصر (2026):  
**https://alwansan.github.io/AI-/**

محتوى تعليمي وتطبيقي يشرح وكلاء الذكاء الاصطناعي، إنشائهم، توظيفهم في إدارة المشاريع الرقمية، وقياس الإنتاجية والمخاطر.

## تجربة التصفح

- قراءة متجاوبة مع الهاتف والكمبيوتر، بدلاً من قالب A4 الثابت.
- فهرس يضم أقسام التقرير الخمسة عشر، مع التنقل والبحث.
- تكبير الرسومات التسعة داخل الفصول، وعرض الغلاف.
- ثلاثة أنماط من سماكة خط الويب: عادي، عريض، ثقيل.
- حفظ نسخة PDF عبر أمر «حفظ بصيغة PDF» أو الطباعة من المتصفح.

## ملفات المشروع

- `index.html`: التقرير العلمي المختصر.
- `styles/site.css`: تصميم القراءة المتجاوب والطباعة.
- `scripts/site.js`: الفهرس والبحث وعرض الصور وخيارات القراءة.
- `صور_التقرير_المعاد_إنشاؤها_2026/`: الرسومات العشر المستخدمة.

## إضافة نسخ PDF الثلاث إلى GitHub Pages

ضع ملفات PDF التالية في مجلد `pdf/` داخل فرع `main`، **بالأسماء المحددة**:

| المسار | الخط |
|---|---|
| `pdf/ArabicUIDisplay.pdf` | ArabicUIDisplay |
| `pdf/ArabicUIDisplayBold.pdf` | ArabicUIDisplayBold |
| `pdf/ArabicUIDisplayBlack.pdf` | ArabicUIDisplayBlack |

تتحقق الصفحة تلقائياً من وجود ملفات PDF وتُظهر زر التنزيل فقط عندما يكون الملف منشوراً بالفعل، كي لا تظهر روابط معطوبة. الخطوط الموجودة داخل ملفات PDF الأصلية مضمنة في تلك الملفات؛ لا يتطلب الموقع نشر ملفات الخطوط نفسها.

> ملاحظة: خيارات أنماط القراءة على الويب تغير **سماكة خط الويب** ولا تعني استخدام ملفات OTF الأصلية حرفياً. وتبقى نسخ PDF الثلاث (عند رفعها) المرجع لعرض كل خط بالضبط.

## الحقوق والمصادر

مراجع التقرير العلمية والتقنية مذكورة في قسم المصادر في نهاية الصفحة. الصور التوضيحية أُنتجت خصيصاً لهذا التقرير، والأمثلة العددية الافتراضية موسومة بوضوح.
